Jaeger Training Calendar — iPhone installation prototype (fictional data only)

This is a static installable web app. No real company data, Microsoft sign-in, or DocGen sync is included.

To install on iPhone:
1. Upload all files in this folder to an HTTPS static website (such as a GitHub Pages site using only fictional data).
2. Open the HTTPS URL in Safari on the iPhone.
3. Tap Share > Add to Home Screen > Add.
4. Open the new Training Calendar icon from the Home Screen.

The calendar is not hosted by this ZIP. Opening index.html in the ChatGPT preview or Files app is NOT equivalent to hosting it on HTTPS; Home Screen installation and service worker offline caching require a compatible web origin.

Important: Do NOT publish real customer names, contact information, assignments, or company records on a public GitHub Pages site. Company IT approval is needed before using real data or company authentication.
